ServerScout for Roblox — Privacy Policy

Last updated: October 10, 2026

ServerScout is an independent browser extension that helps users find and join public Roblox game servers. It is not affiliated with, endorsed by, or sponsored by Roblox Corporation.

Information handled on your device

The extension stores your region and player filters, up to 10 recent server sessions, and up to 200 server-feedback records in local browser storage associated with Roblox pages. These records can include Roblox game and server identifiers, game title, join and leave times, player counts, detected region, and ping information. Temporary location and server lookup caches may be held for the current browser session. The extension does not sync these records to a ServerScout account or server. They remain in the browser profile and can be removed by clearing Roblox site data in your browser.

Roblox requests

When you use server search, ServerScout requests public server information from Roblox. When you ask to join or check a server, it may contact Roblox's authentication, server, or join endpoints using your existing Roblox browser session. Session cookies are used only for requests to Roblox. The extension does not send your Roblox password, cookies, or session credentials to the extension developer or to the geolocation and region-data providers. A Roblox anti-forgery token may be read temporarily from the Roblox page and used only with Roblox requests needed for the requested feature.

Third-party services

External location and region lookups are off by default. You can enable or disable them in the extension's location area. Before enabling, the extension explains which providers are contacted and what network information they receive. If enabled, these providers receive requests from your public IP address:

  • ipwho.is provides approximate location data. It receives a request to determine your approximate location and may also receive Roblox server IP addresses for geographic lookup.
  • data.roseal.live provides a datacenter/region reference dataset. The extension downloads and caches this dataset locally for up to seven days. The request does not include Roblox account credentials.
  • The extension contains an optional Discord link. Discord is opened only if you choose to follow that link, and its own privacy policy then applies.

These services are operated by third parties. Their handling of request logs and network metadata is governed by their own policies. ServerScout does not operate a service that receives your search history, feedback, Roblox account details, or server-session history. If you leave external lookups disabled, the extension uses its bundled region data where available and does not make new requests to ipwho.is or data.roseal.live.

Analytics and advertising

ServerScout does not include an analytics system, advertising, or a developer-operated account service.

Your choices

You can stop using the extension at any time by disabling or removing it in Microsoft Edge. You can clear locally stored preferences, history, and feedback by clearing site data for Roblox in Edge. Search and region lookup features require an internet connection and may not work when Roblox or the third-party data providers are unavailable.

Contact

For questions or privacy requests, use the ServerScout support Discord.
